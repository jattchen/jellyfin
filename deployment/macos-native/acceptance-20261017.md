## HTTPS 播放回归与修复

同一普通用户、同一候选，在本机 HTTP 的 playback prepare 为 200，经可信 HTTPS 代理为 500。原因是插件用外部 `Request.Scheme=https` 回连实际只听 HTTP 的 8097。修复改用实际连接的 TLS feature 判断协议，不改固定 loopback 地址和监听端口。
