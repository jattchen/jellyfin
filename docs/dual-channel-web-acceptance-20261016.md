## 权限、文件生命周期和故障证据分层

**真实隔离宿主状态变更：**

- 普通测试用户仅授权PilotCandidates库时返回候选，文字片段可读取；撤权后搜索为空、原文字片段404。模型请求已派发而缓存响应尚未回来时撤权，最终仍为空。最终带向量缓存的版本重新验证了该时序，使用该用户尚未编码缓存的另一条冻结题。
- 普通用户请求管理员 `diagnostics` 返回403，没有借管理员权限导入或查询。启用库移除后，搜索为空、原文字片段404；原配置恢复。
- 文件替换/删除只作用于新建的私有D2副本。先把隔离宿主中原D2条目的路径临时指向保留原mtime的副本，确认旧文字候选仍200；实际改变副本后旧候选409 `stale`，搜索不返回该样片，网页点击旧结果提示失效且没有视频元素/播放。移走副本后旧候选仍被拒绝，搜索仍不返回该样片。
- 故障结束后恢复原条目路径；插件测试库七张表与事前备份逐行一致。原14条样片未改变。损坏副本、失败记录和备份保留。

**明确的故障注入/合成反例：**

- 临时HTTP网关注入模型元数据503：真实网页走模型不可用分支，原标题仍可用；没有停止或修改原模型服务。
- 临时网关注入processing签名不符：搜索为 `incompatible`、文字点击409、零嵌入POST；恢复真实元数据后正常。
- 4秒迟到响应是缓存传输延迟注入，不是声称真实模型自然出现该延迟。
- 单元测试另覆盖非法映射、单路/签名不兼容、文字表示版本变化、同区间取强、相交不合并、全榜严格降序，以及查询向量复用后撤权/内容失效仍隐藏、模型异常不被缓存掩盖。

不把合成向量、HTTP故障注入、接口200或测试通过单独当作实际播放、手机或生产验收。
