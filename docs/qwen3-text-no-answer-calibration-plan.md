# 对白文字检索：有限无答案校准方案

状态：2026-10-15，用户在文字检索 B 的 Top3 4/5 后，选择“无答案校准方案”。**本轮仅形成方案；下列标签、校准、验证均未执行，没有新增模型推理或产品改动。** 真正运行需另行批准。关联 [阶段 B 的实际结果](qwen3-text-retrieval-pilot.md)。

## 要回答的问题

现有文字向量能找回大部分目标，但对任何文字查询都能排出“最接近”的候选。相似度高不证明说过相应内容，也可能把含义相反的话排高。现在只检验一种简单策略：为**同一文字表示**设置单一相似度下限，能否保留正确对白并拒绝无答案。不引入新 ASR、embedding 模型、重排、关键词规则、融合或生成式判断。

不能用原七题挑下限：这些分数已经看过，而且当前只有两个负例。D1 排第 4 是排序问题，调下限不会把它升到前三。原七题继续作为已见过的冻结回归集，不能冒称未见测试集。

## 预先固定的判定规则

候选仍按 B 的归一化点积降序，同分按固定文档 ID，不修改分段、查询、排序或权重。候选分数 `>= T` 才作为可显示的相关结果；没有候选过线则明确表示未找到明显匹配，仍可保留另行说明的弱候选，但不能借显示措辞算拒绝成功。

1. **只运行 16 条校准题。** 每个负例取所有 25 候选中的最高分。令 `T` 为“八个负例最高分的最大值”之上的最小可表示浮点数，避免同分时负例过线。任何更高下限只会损失更多正例。
2. 校准必须八个负例全部拒绝，且至少 **7/8 正例**的完整、正确文档在 Top3 且达到 `T`，其 5–10 秒区间具有内容证据。若做不到，判定“本批校准未找到满足要求的单一下限”，停止，不自动尝试其它阈值公式、权重或模型；不为了验证分数而继续运行八条留出题。
3. 校准通过后，保存下限、算法、模型与候选签名，才运行八条留出题。要求 **4/4 正例**完整目标在 Top3 且过线，**4/4 负例**全部拒绝；任一不满足即记验证未通过，不用验证题重调下限。
4. 同一个下限应用于已保存的原七题，不发新推理。要求原五条对白仍至少 **4/5** 完整目标在 Top3 且过线，原 N1/N2 均被拒绝。D1 仍第 4 就继续按失败保留，不能把改显示条数算排名改善。
5. 校准正例、校准负例、留出正例、留出负例、原七题分别列成绩。即使全部过关，也只证明这一固定候选集的有限规则可继续验证；不称整库无误报、多语种通过或功能已经上线。

这是检验单一下限是否成立，不保证能找到合格下限。尤其近似但含义相反的句子可能仍有高相似度，不能把这种失败改写成“用户问题不合适”后删题。

## 执行与停止边界

本轮授权若后续获得：先冻结内容标签，再最多 16 条校准 query；只在校准通过后增加最多 8 条验证 query。累计最多 24 条新 query，0 新 document、0 ASR、0 对齐，0 新素材。所有推理顺序派发、完整响应后才发下一条；超时或断线的完成状态未知则停，不重发或继续叠加。成功响应保留，失败和取消不冒充完成。

实验文字向量、下限和状态只放私有试验目录，不写入现有联合窗口或质量设置。原视觉/联合 `.35` 不变，也不用于本方案。Jellyfin、模型服务、网页、服务自启与生产配置不改；不下载模型、不增加服务、不处理完整视频。真正接入产品和完整视频链路仍是之后的决策。

后续用户转向三路独立 embedding 的评分设计，本单文字计划/试验不自动继续；当前算法调研与未验证推荐见[三路评分调研](trimodal-score-fusion-research.md)。
